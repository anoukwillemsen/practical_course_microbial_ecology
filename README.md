# Practical course data analyses
Companion repository for the 301485-1 Advanced Practical Course in Microbial Ecology - Exploring Organism Interactions in Nature


## Overview and Project Description
We will analyse two different datasets you generated during the course. 
  Dataset 1: 18S rRNA Sanger sequencing data of the host
  Dataset 2: digital PCR of different time points of the viral infection cycle
